# Pooh CRM

A personal project for exploring the Etsy Open API.

## What it does
Connects to my own Etsy shop data to pull sales and listing information
for personal market research — helping me understand product performance
and refine my own offerings before launch.

## Status
Work in progress / personal use only. Not commercial, not public-facing.

## Stack
Next.js, Prisma, Tailwind, shadcn/ui

## Scope
Read-only access to shop and sales data via the Etsy API.
